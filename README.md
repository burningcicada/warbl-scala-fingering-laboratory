# WARBL Scala Fingering Laboratory v1.0

Launch `WARBL_Scala_Fingering_Lab_v1_0.html` in a current Chromium-based desktop browser. The application is self-contained; no installer or server is required.

## Why not just learn one WARBL fingering and use it for every Scala file?

**You can.** For many players, keeping one familiar WARBL fingering system may be the best approach. The WARBL can keep producing the same MIDI notes from the same fingerings while a Scala-aware instrument or retuning system determines the resulting pitches.

The Laboratory lets you compare three choices:

- **Familiar mapping** — maximum muscle memory.
- **Scale-specific mapping** — arrange the fingerings around that particular scale.
- **Hybrid mapping** — keep most familiar fingerings and change only the ones that benefit from another placement.

The Scala file itself does not have to change. The Laboratory changes the relationship between physical fingering and scale degree.

**The value of the Laboratory is not that every scale needs a new fingering. It is that the musician can test whether the familiar fingering is still the best way to play that scale.**

## Important boundaries
Advanced yaw/button tuning navigation is opt-in and should be tested with the performer’s active WARBL profile; external synth/DAW compatibility remains destination-specific.

The embedded favicon uses the approved WARBL SFL W/F/L/S hexagonal identity. File-manager icons for `.html` files remain controlled by the operating system/browser association.
