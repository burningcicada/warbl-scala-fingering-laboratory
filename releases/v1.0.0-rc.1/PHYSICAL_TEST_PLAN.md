# v1.0.0-rc.1 — Physical WARBL2 Acceptance Plan

Keep the test environment as close as possible to the successful recovered.7 session.

1. Normal Lab Fingering play: weak/strong attacks, rapid repeated attacks, release/re-attack.
2. Specifically listen for any one-off low or wrong attack at fingering transitions; mark the moment and retain the Flight Recorder if heard.
3. Sustain a note while adding vibrato/bend and changing fingering; confirm no frequency jump/drift and Pitch Geometry tracks physical + sounding states appropriately.
4. Load a Scala with very close degrees, especially the 2.686567-cent pair; audition Dry with minimal vibrato first, then normal expressive playing.
5. Exercise Pattern Tutor / Practice: Generate path, Play/begin, Export native exercise, Start/Replay/Stop.
6. Exercise Extended Mapping: Generate/refresh systems and Download DAW workflow.
7. Exercise principal exports and Copy 256 values.
8. Use Print / Save PDF, return without moving fingers, and confirm the Lab reacquires current raw fingering before normal play resumes.
9. If appropriate, run the WARBL2 custom-chart install flow and confirm acknowledgement; do not conflate this with exact Scala pitch, which remains Lab/receiver tuning truth.
10. Keep Automatic verification strict; conflict/no-anchor states must fail closed rather than guess.
